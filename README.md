## UPDATE

A new version of **Gmod Theme Engine** is coming soon to the Garry's Mod Workshop, and this time without breaking any rules!

This new version will include a lot of new features, improvements, and optimizations.

### Planned features

* Support for installing and loading different themes.
* Fully customizable background, now with fewer issues and better stability.
* Support for custom menu music.
* Support for changing Garry's Mod menu sounds.
* Support for changing fonts and adding new ones.
* Option to reset the font back to the one used by the current theme.
* Spawnmenu skin customization, currently only available in singleplayer.
* Improved handling of the Garry's Mod Workshop menu, since it can lag a lot sometimes.
* Added a developer button in singleplayer to reload addons and even load new ones without restarting the game.
* A console command for the developer reload system is also included.

This should be finished in a few days... hopefully, if nothing breaks lol :c
